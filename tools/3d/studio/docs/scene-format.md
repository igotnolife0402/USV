# Studio: scene format

The AI interface: scene JSON, objects, materials, textures, animation, effects, looks. Back to the [README](../README.md).

One db document per project: `projects/<id>`. Objects are keyed by id so an AI changes one object with one `update`.
```json
{
 "name": "Castle", "v": 1, "updated": "2026-11-12T10:00:00Z",
 "objects": {
  "base": {"type": "part", "shape": "box", "name": "Base", "parent": null,
           "pos": [0, 0.5, 0], "rot": [0, 0, 0], "scale": [1, 1, 1], "size": [8, 1, 8],
           "color": "#7f8c99", "material": "Slate", "texture": null,
           "visible": true, "locked": false, "anchored": true, "order": 0},
  "tower": {"type": "group", "name": "Tower", "parent": null, "pos": [3, 1, 3]},
  "roof": {"type": "mesh", "geo": "g-9a1c", "parent": "tower", "pos": [0, 4, 0], "color": "#b5452f"},
  "sun": {"type": "light", "kind": "directional", "pos": [5, 10, 4], "color": "#ffffff", "intensity": 2},
  "line1": {"type": "stroke", "points": [[0,1,0,1], [1,2,0,0.8]], "radius": 0.05, "color": "#ffcc00"},
  "chair": {"type": "model", "src": {"asset": "<assetId>"}, "pos": [1, 0, 0]}
 },
 "anims": {
  "wave": {"name": "Wave", "len": 2, "fps": 30, "loop": true,
           "tracks": {"tower": {"rot": [[0, [0,0,0], "ease"], [1, [0,30,0], "ease"], [2, [0,0,0]]]}}}
 },
 "textures": {"t-bricks": {"kind": "procedural", "pattern": "bricks", "colors": ["#a0522d", "#d8c8b8"], "scale": 4}},
 "env": {"bg": "#1b1d22", "grid": true, "fog": null, "light": "studio"},
 "camera": {"pos": [12, 9, 12], "target": [0, 1, 0], "fov": 50, "ortho": false}
}
```
- Units: studs (1 = 1 m). Y is up. `rot` is degrees XYZ. `color` is `#rrggbb`.
- Part shapes: `box, sphere, cylinder, wedge, cornerwedge, cone, torus, plane, capsule`. `size` is the part's full size. Cylinder, cone and capsule run along Y; a wedge's tall side is at +Z.
- Part fields and defaults: `size [4,1,2]`, `color #a3a2a5`, `material Plastic`, `transparency 0` (0..1), `anchored true`, `negate false` (a hole for CSG). Mesh adds `smooth`. Light: `kind point|spot|directional`, `intensity 2`, `range 16`, `angle 45`, `shadow false`.
- A new project (`file.new`) holds one locked `Baseplate` 64×1×64 whose top is y 0 (`empty: true` skips it).
- Set an object to `null` to delete it (the page compacts nulls). Missing fields use the defaults above.
- Track keys: `[time, value, ease?]`; ease is `linear, ease, smooth, in, out, step, bounce, elastic` (`smooth` = sine in-out: keys on the peaks of a wave replay it exactly, so a few key poses do the work of a key per frame); channels `pos, rot, scale, color, visible`.
- Mesh geometry lives in `projects/<id>/geo/<geoId>`: `{"verts": [x,y,z, ...], "faces": [[a,b,c,d], ...], "uvs": [u,v, ...] | null}`. Faces are polygons (quads or n-gons, counter-clockwise). Geometry is immutable: an edit writes a new geo id. Over 240 KB goes to the assets store as JSON (`{"asset": "<id>"}`).
- Painted or image textures: `projects/<id>/tex/<texId>` `{"kind": "image", "data": "data:image/webp;base64,..."}`, or `{"asset": "<id>"}` when large.
- Sides: every face renders from both sides, so flipped normals never show a part see-through. A different inside look: `"backColor"` and/or `"backTexture"` (texture id) on the part; then the outside is front-only and the inside uses those (2026-11-23).
- Looks (`plugins/look.js`, Scene panel Look, `env.look`): normal (Neutral tone mapping); `"toon"` (cartoon only: ink outlines from one inverted-hull pass drawn straight from a list of solid meshes, Standard view, brighter environment; box parts take `bevel` so outlines close); `"roblox"` (the owner's thumbnail style: no ink, AgX with a punchy filmic look (power 1.35, saturation 2.0) as three's CustomToneMapping, exposure 1.8, normal environment). Hero glow: `glow: "#ffd21f"` (optional `glowWidth`, px at 1080p; default 14 toon/normal soft glow, 6 roblox crisp thin rim) on any object but text: outside its visible silhouette only (never through a wall in front), under the ink, live in any look (only while a glow object exists, mix scissored to the halo) and rendered. `look.render` (Render image) at 1920x1080, 4x MSAA: solid lit meshes, screen-space AO (16 hemisphere samples, depth-aware blur, applied to the shown colour; roblox stronger and wider), then glass, effects, text and unlit; ink (toon), bloom (roblox: only light energy above 2.5, so lit walls never halo), halo, vibrance, contrast; roblox adds a slight sharpen and vignette; every look dithers the 8-bit output (no banding). Render only (iPhone speed): AO, shadow maps at 4096 (sun) and 2048 (other shadow lights) with a softer PCF radius (r186 dropped PCFSoftShadowMap), all put back after. `{ao: false}` turns AO off (tests). Caps (`test/look.mjs`): 60 parts at 1920x1080 under 8 s, the reference scenes under 8 s, live toon frame within 1.5x of normal, a hero glow adds under 1 ms.
- Baseplate (thumbnails stand on it unless another ground tells the story better): texture def `{"kind": "procedural", "pattern": "studs", "colors": ["#ffffff"], "count": 1, "scale": 1}` (one square tile with a raised round stud per stud), on `{"type": "part", "shape": "box", "name": "Baseplate", "size": [256, 1, 256], "pos": [0, -0.5, 0], "color": "#2bc22b", "texture": <its id>}` (grey: `#a3a2a5`).
- Torus `size`: [outer diameter, tube thickness, depth]: a 0.15 tube is a ring (a tube of half the diameter fills it to a disc).
- Text for thumbnails (`plugins/text.js`): `{"type": "text", "text": "+999", "font": "Luckiest Guy" | "Bangers" | "Lilita One" | "Titan One" | "Bungee", "size": 1.5, "fill": [top, ..., bottom], "stroke": "#3a1500", "strokeW": 0.13, "shadow": "#000", "shadowOff": [0.05, 0.08], "glow": "#ffb300", "skew": -8, "tilt": 10, "face": "camera" | "fixed", "overlay": true}`: gradient fill, outline, shadow, glow and a glossy top on a card; `overlay` draws it over everything; fonts load from Google Fonts on first use.
- Flipbook effects (`plugins/vfx.js`): `{"type": "flipbook", "tex": <tex-store id of a sprite sheet>, "grid": 4, "frames": 16, "life": 1, "start": 2.0, "loop": false, "dur": 1, "fps": 16, "size": 8, "blend": "normal" | "add", "flat": false, "shape": "card" | "beam", "length": 10, "speed": 0}`: a camera-facing card (a ground decal with `flat`; with `shape: "beam"` a 3D glowing volume along the object's local +X, `size` wide and `length` long, that keeps its direction from every view and is a disk end-on; `speed` studs/s shoots it out, 0 shows it whole) that plays the sheet on the clip's timeline from `start` for `life` seconds (`loop`: `dur` seconds at `fps`), hidden otherwise. Big sheets: upload them as artifact assets and set `projects/<id>/tex/<texId>` to `{"asset": "<id>"}`.
- Timing effects in the Animate tab: every flipbook is a timeline bar (drag it to move `start`, its right edge to stretch `dur`/`life`: `vfx.time`); the Effects button lists this project's sheets plus the hub's shared library (db collection `vfx`, docs `{name, asset, grid, frames, fps, loop, life, dur, size, blend}`); drag one onto a row and it plays from that time parented to that object (`vfx.add`), tap adds it at the playhead on the selection. A parent row sums its children's keys, so a folded rig shows its key poses and dragging one moves the whole pose. A row that holds effects shows a thin blue strip per effect inside. On a phone the dock keeps its own height (default 40% of the screen; drag the tab bar), so four rows fit under the toolbars.
- Shadows for dense meshes: `castShadow: false` on a part or mesh stops it casting; `shadowOnly: true` makes an invisible stand-in that only casts (never drawn in a view, picked or exported). A coarse stand-in for a 100k-triangle mesh keeps the same shadow at a quarter of the shadow-pass triangles.
- Playback on a slow GPU: while something plays and frames take over 28 ms, the viewport draws fewer pixels (down to 1x); full sharpness returns when it stops (`vp.stats.dpr`).
- Texture defs (`scene.textures`, shared by id): procedural `{kind: 'procedural', pattern, colors, count, detail, seed, res, scale, offset: [u, v], rot}` (patterns: `PATTERNS` in plugins/texture.js; detail surfaces `rock, woodgrain, brushed, fabric, asphalt, road, grass, sand, water, grip, carbon` take colours [base, dark, light] (road adds centre and edge line paint), count = feature size, detail = contrast; they draw as whole-image `tone(p, N, T)` passes, under 30 ms at 512 px, test/texture.mjs); image `{kind: 'image', src: <tex-store id>, name, res, aspect, scale, offset, rot}`; paint adds `paint: true, rev, base` (each stroke bumps `rev`, so undo swaps pixels); paint on a part adds `uv1: 1` (the part's 3×3 atlas layout); `parts.toMesh` bakes that layout into the mesh's `uvs` and drops `uv1`, so the paint stays in place. Object surface overrides: `roughness, metalness, emissive, emissiveIntensity, transparency`.
- Texture plugin exports (plugins/texture.js): `imageEntry(app, id, def)`, `canvasOf(app, texId)`, `projectUV(geo, 'box'|'planar'|'cylindrical'|'spherical'|'atlas', axis)`, `uvBounds(geometry)`, `encode(canvas, type, q)` (worker, off the main thread), `makeCanvas(w, h)`.
- Roblox plugin exports (plugins/roblox.js, no DOM): `toRbxmx(scene, {ids, baseplate, ...exportCtx(getGeo)})` → `{xml, meshes, notes, counts}`, `toLua(scene, opts)` → `{lua, ...}`, `readRoblox(text|bytes)` + `fromRbxItems(list)` (XML .rbxmx/.rbxm in), `eulerToMat`/`matToEuler` (XYZ degrees ⇄ CFrame R00..R22). Commands `roblox.export|exportLua|import`, hidden `roblox.rbxmx|lua` return text.
- Home page list: `meta/<id>` `{name, updated, count, thumb}` (small; the page keeps it in step).
- Temporary models (`plugins/scaffold.js`): `temp: true` on an object (and so everything under it) keeps it in the tab, playing and animating like any object, but out of every export (glb/gltf/obj/fbx/dae/stl/ply/3mf/usdz, Roblox rbxmx/lua, scene .json, MP4 video). The Explorer lists them last under **Temporary models · not exported** with a show/hide eye (`temp.show`). Add menu: `temp.ball` (chrome), `temp.sword`, `temp.marker` (x/y/z axes), `temp.box`; context menu `temp.make` toggles the flag on the selection. Use them to test physics, align, hold or throw things.
