# Studio: add a capability (plugin API)

Plugin shape and cookbook. The `app`, viewport and UI APIs and built-in commands: [plugin API](plugin-api.md). Back to the [README](../README.md).

Make `plugins/<name>.js`, add one line to `plugins/index.js` and its `modulepreload` line to `index.html`. Import a big library inside the command that needs it (`await import(...)`), never at the top. Template:
```js
export default {
  id: 'hello', name: 'Hello',
  commands: { 'hello.cube': { label: 'Add hello cube', key: 'Shift+H', icon: 'cube',
    run(app, args = {}) { return app.add({ type: 'part', shape: 'box', size: [1,1,1], color: args.color || '#3d8bfd' }) } } },
  menus: { Add: ['hello.cube'] },          // menu name -> command ids ('-' = separator)
  modes: [], tools: [], panels: [], importers: [], exporters: [], types: {},
  init(app) {}                            // may be async; runs after every plugin is registered
}
```
- Every change goes through `app.run(cmd, args)` or `app.transact(label, fn)` so undo, sync and AIs see it.
- **Command def**: `{label, icon, key ('Ctrl+Shift+U', 'Numpad1', or an array), run(app, args), enabled?(app, args), checked?(app), hidden? (not in palette/menus), noUndo? (skip the undo step), menu?}`. `app.run` throws `Unknown command: <id> (did you mean <ids>?)` / `Not available now: <label>`; `app.exec` shows the error as a toast. An async `run` must wrap late changes in `app.transact`.
- **Tool def**: `{id, label, short? (phone bar label, about 8 letters), icon, key, mode?, order, onActivate(app), onDeactivate(app), onDown(ev) -> true to capture, onMove(ev), onUp(ev), onCancel(ev), onHover(ev)}`. `ev = {x, y, clientX, clientY, ndc, ray, hit, button, pointerId, pointerType, shift, ctrl, alt, pressure, native, vp}`; `hit = {id, point, normal, object, face, faceIndex, distance, uv}` or null.
- **Mode def**: `{id, label, short? (phone mode pill label), icon, order}`; `app.setMode(id)`. Core registers `build`.
- **Panel def**: `{id, label, icon, mode?, where: 'right'|'bottom', order (50), when?(app), render(el, app) -> cleanup?, refresh?(el, app, ev)}`. Without `refresh` the panel re-renders on select and mode; `ev.type` is `change|select|mode|time|project|refresh`.
- **Panel controls** (`app.ui.controls`): `number(label, {read() -> {v, mixed}, write(v), step, min, digits})`, `vec3(label, {get(obj) -> [x,y,z], set(obj, arr) -> patch, step, min})`, `text, color, select, toggle, slider, info(label, read)`, `row`, `group(el, title)`, `live(label, fn) -> {start, set, stop}` (one undo step for a drag), `once(label, fn)`. Each returns `{el, update}`.
- **Importer** `{ext: ['obj'], label, load(file, app)}`; **exporter** `{ext, label, save(app, opts), rank? (shelf order), zip? (always a .zip), hint}`; **type** `{build(obj, app, ctx), update(o3d, obj, app, ctx), defaults}`.
- Events: `app.on(name, fn)` / `app.off`: `change {objects, anims, textures, top, source, keys}`, `select`, `mode`, `tool`, `time`, `project`, `history`, `prefs`, `registry`, `viewport`, `camera`, `render`, `save`, `saved`, `synced(ids)` (core rebuilt those Object3Ds at rest pose).

### Cookbook (all a plugin needs; never read core to find it)
- **Imports**: `three`, `three/addons/...` (loaders: GLTF OBJ MTL FBX STL PLY Collada 3MF TDS VOX VRML AMF USDZ SVG; exporters: GLTF PLY STL USDZ; Studio's own OBJ, FBX 7.4 binary, Collada and 3MF writers, plus the STL, PLY and USDZ exports, are in plugins/export.js, which imports `exportRoot, zipFiles, MIME, drawable, dataURLBytes, safe, toBytes` from io.js; zip: `three/addons/libs/fflate.module.js`), `three-mesh-bvh`, `three-bvh-csg`. Core (plugins import it relatively, like parts.js line 3): `icon, addIcons, isPhone` from `core/ui.js`; `toBufferGeometry(geo, {smooth}), fromBufferGeometry(bg, {weld, quads, uv}), computeBounds, partGeometry, strokeGeometry(points, radius), materialFor, MATERIALS, SHAPES, uid` from `core/model.js` (fromBufferGeometry's `uv` names the attribute to keep, e.g. 'uv1'; seams split verts); `parseNum, fmt` from `core/panels.js`. Load big loaders lazily with `await import()`.
- **DOM**: `const h = (tag, cls, html) => { const e = document.createElement(tag); if (cls) e.className = cls; if (html !== undefined) e.innerHTML = html; return e }`. Classes: `.sec .sec-h .sec-b` (panel section), `.btn .btn-row`, `.seg .segb` (segmented), `.chip`, `.inp .num .sld .tog`, `.swatch .swatches`, `.grow .mono .mute .kbd`, `.ic .ib` (icon, icon button), `.menu .m-item`, `.thumb`. Colours: `var(--bg --panel --panel2 --line --text --mute --accent --select --danger --ok --hover --field)`, row height `--h`, radius `--r`. Own CSS: one `<style id="pl-<id>">` added in `init`, classes prefixed `<id>-`. Prefer `app.ui.controls` over hand-built inputs.
- **Icons**: `addIcons({knife: 'M2 14 14 2 M10 2h4v4'})` (16×16 viewBox stroke paths) at module top; then use the name in `icon:`.
- **Keys**: core dispatches command keys only, and a command with `mode: '<id>'` wins a clash in that mode. A tool's `key` is only shown in its tooltip: to give a tool a key, add a command `{key, mode, run: app => app.setTool(id)}` (see draw.js `toolCmds`). Never add keydown listeners.
- **Modes**: `{id, label, icon, order, gizmo: true}` keeps core's move/rotate/scale gizmo in the mode; `ownGizmo: true` lets the mode drive `app.viewport.gizmo` (a TransformControls) itself; `app.viewport.updateGizmo()` re-syncs. Tools and panels of a mode set `mode: '<id>'`; `where: 'bottom'` docks a panel under the viewport (a sheet on phone).
- **Meshes**: `const g = app.geo.put({verts, faces, uvs})` returns a geo id; then `app.add({type: 'mesh', geo: g})` or `app.set(id, {geo: g})` inside a command or `app.transact` (one undo step). Read: `app.geo.peek(g)` (sync, null if not loaded) or `await app.geo.get(g)`. Drawn object: `app.viewport.objects.get(id)` (geometry from `toBufferGeometry`). Part to mesh: `app.run('parts.toMesh', {ids})`. While dragging, change the Object3D's geometry directly and `requestRender()`; write one new geo when the drag ends.
- **Overlays** (points, edges, brush ring): add to `app.viewport.helpers` with `userData.helper = true`, call `app.viewport.requestRender()`, remove them on mode or tool exit.
- **Rendering** is on demand: call `app.viewport.requestRender()` after changing any Object3D. Per-frame work only while needed: `const stop = app.viewport.loop((dt, t) => { ... })` (return false to stop).
- **Animation**: core keeps `scene.anims` and `app.time` (`setTime` emits `time`) but never plays them: the anim plugin samples tracks and sets the Object3Ds, and re-applies its pose on `synced`. Hooks it sets: `app.poseOf(id) -> obj` (posed values the gizmo starts from) and `app.onTransform(vals, label) -> true` to take a gizmo edit (`vals = [[id, {pos|rot|scale}]]`) as keys instead of `app.set`.
- **`app.anim`** (anim plugin): `toClips({root, all}) -> THREE.AnimationClip[]` (one per clip with tracks, sampled at its fps, tracks named `<node uuid>.position|quaternion|scale`; `all: true` adds `material.color` and `visible`; `root` maps ids through `userData.id` in a copied scene), `evaluate(t)` (poses Object3Ds only, never the scene), `play()`, `pause()`, `stop()`, `rest()`, `sample(keys, t, ch)`, `EASE`, `modelClips()`, getters `playing`, `clip` (current clip id; imported GLB clips are `m:<objId>:<i>`, read-only), `selectedKeys`. Commands: `anim.new {name, len, fps, loop}`, `anim.key {ids, t, channels, values}`, `anim.setKey {id, ch, t, value, ease}`, `anim.ease {ease, keys}`, `anim.moveKeys {dt, keys}`, `anim.selectKeys {keys|all|ids|t}`, `anim.deleteKeys`, `anim.copyKeys`, `anim.pasteKeys`, `anim.autokey {on}`, `anim.time {t|frame}`, presets `anim.spin|bob|bounce|pulse|walk|wave {ids}` (walk and wave need the R6 rig; limb parts get pos keys so they turn about the shoulder or hip).
- **Files**: `app.store.download(filename, data)` (viewer confirms; `.glb .obj` etc. go inside a `.zip`; the Export dialog shares the real file through `navigator.share` first where `navigator.canShare({files})` allows it: on touch devices always, on desktop for types a download would zip), `app.store.upload(blob, type) -> {id, url}` (assets). Importers and exporters are listed in `app.importers` / `app.exporters`.
- **Tests**: `test/<id>.mjs`: `export default async function (t) { await t.test('name', async () => { const s = await t.open(); await s.project('Name', {empty: true}); const id = await s.run('<id>.cmd', {...}); const o = await s.eval(id => window.studio.app.obj(id), id); t.eq(o.type, 'mesh', 'msg'); s.noErrors() }) }`.
