# 3D rules
- Blender MCP (only when the owner names Blender; default tool is Umbrio Sandbox): call get_addon_status and get_scene_info first; save the .blend before every execute_blender_code.
- Split complex Blender work into small scripts; `look` after each meaningful step.
- Build custom meshes in the Umbrio Sandbox (start from the model library); no asset-library imports or AI generators unless the owner names them.
- Rescale every import by its world bounding box to real-world meters and place it on the ground.
- Find shader nodes by type, never by localized name; read enum identifiers, never hardcode them.
- Apply transforms and export GLB with +Y up; materials = Principled BSDF + image textures only.
- three.js: pin versions in the import map, set sRGB output, tone mapping and an environment map.
- Owner quality bar: real modelled detail, PBR, never placeholder blocks; an owner reference is the target. Start from the closest tools/3d tool (playbook table).
- Finished piece = fresh Studio tab, exact model, live build (first part into the tab first); only the model asked for; test helpers temp: true.
- Z-fight gate: tools/3d/zfight check passes on the tab read-back before live/finished; never stack decals/rugs/trims on a surface; judge on phone depth (SHOTS_DEPTH16=1).
- Limits: geo doc <= 225 KB, batch <= 50 writes / 1 MiB, <= 19k tris per Roblox MeshPart, neon as Neon parts, ~150 draw calls on phones.
- Studio code: every boot module modulepreloaded, pinned CDN versions, lock each speed gain with a test cap; run tools/3d/studio/test/run.mjs on the touched suite.
- No session or machine paths in tool files: env vars (NODE_TOOLS, CHROME, DEPS, SCRATCH) or relative paths; outputs go to scratch, never the vault.
- Browser mini-Blender: extend Studio first; otherwise fork the three.js editor at a pinned tag (keep MIT LICENSE); do not rebuild gizmos/undo/tree.
- Mobile: Umbrio builds run in the cloud session (generators + live tab writes); only an owner-named Blender step becomes a `*.blend.py` + queued run.
- Done = checklists/3d.md; new failures go into domains/3d/errors.md.
