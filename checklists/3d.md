# Checklist: 3d
- [ ] Editors: used the [3d-editor skill](.claude/skills/3d-editor/SKILL.md). Models: followed the [3d playbook](domains/3d/playbook.md).
- [ ] No overkill: one big effect when the whole thing completes, or small subtle ones throughout; never a big effect per step ([owner](profiles/owner.md)).
- [ ] Owner floor met ([profiles/owner.md](profiles/owner.md)): full detail, no placeholders, scope exactly as asked, original (no clones).
- [ ] Models: [detail floor](domains/3d/detail.md) gate passes (`tools/3d/detail/detail.py` or `tools/roblox/detail-check.mjs`): custom meshes, textures, many combined parts.
- [ ] Hero pieces: blueprint first (references: hero shot, exploded, 360; dimensions, part counts, colours, materials, moving parts).
- [ ] No z-fighting: nothing stacked or coplanar (one inlay plane, or >= 1.5 cm apart); checked on the target read-back, not local files.
- [ ] Normals/winding face outward (mirrored or negative scale flips them).
- [ ] Temporary helpers (test props, projectiles) excluded from every export.
- [ ] Heavy scenes: payload size measured before live writes; mass-repeated pieces merged one mesh per colour; 10 heaviest models optimised without changing the look.
- [ ] Animation: separate critic pass on stiffness, poses, timing, transitions; pass/fail with exact fixes.
- [ ] Model: real scale (1 unit = 1 m; Roblox in studs), origin at base, transforms applied, sane poly count.
- [ ] Materials set on shader node inputs (not viewport color); textures packed or beside the export.
- [ ] Export (glb/fbx) reloads cleanly (three.js GLTFLoader or re-import).
- [ ] Editor: orbit/pan/zoom, select, transform gizmo, explorer/outliner, undo, save/load, import/export each work once.
- [ ] .blend saved before every Blender MCP execute; binaries out of git, generator script committed.
## Verify (one)
- pc: Blender `look` screenshot of the result, or the editor in a browser exercising each tool once.
- mobile: three.js Artifact preview; append "run bpy script, export glb" to queue/pc.md.
