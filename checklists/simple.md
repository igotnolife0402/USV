# Checklist: simple (< 1 min)
- [ ] Answer directly or make the one edit. No tools beyond the routed notes (+ one grep/read if the answer needs it).
- [ ] No plan, no research, no sub-agents, no scaffolding.
- [ ] Output is the answer itself: no preamble, no recap.
- [ ] Unsure of a version/API fact → say so in one line; research only if asked.
## Verify (one)
- Edit: re-read the changed lines or run the file's syntax check (`node --check`, JSON parse). Answer: self-check against the routed note.
## Log
- One line in log.md: `## [date] simple / topic`. Lesson only if a note was wrong or missing (fix the note too).
