# Studio: plugin API

`app`, viewport, UI and built-in commands. Plugin shape and cookbook: [plugins](plugins.md). Back to the [README](../README.md).

## App
`obj(id)`, `ids()`, `children(parent)`, `descendants(id)`, `topLevel(ids)`, `worldMatrix(id)`, `sceneData()`, `isHidden(id)`, `isLocked(id)`, `add(obj) -> id`, `set(id, patch)`, `update(map)`, `remove(ids)`, `rename`, `reparent`, `group`, `ungroup`, `duplicate(ids, {offset})`, `copy`, `paste`, `select(ids, {add, toggle})`, `selection`, `putAnim`, `patchAnim`, `putTexture`, `setEnv`, `setCamera`, `transact(label, fn)`, `undo`, `redo`, `setTool`, `setTime`, `setPref(k, v)` (`prefs: {snap, moveSnap 1, rotSnap 15, space, surfaceSnap true}`; with `surfaceSnap` a dragged part rests on the surface under the pointer, like Roblox Studio, and an explicit `pos` never snaps), `toast(msg, kind)`. Blob stores `app.geo` / `app.tex`: `put(data, id?) -> id` (`g-`/`t-`), `peek(id)`, `get(id) -> Promise`. Hooks a plugin may set: `app.loadModel(src, obj) -> Object3D`, `app.textureFor(id, tex) -> Texture` (`undefined` falls back).

## Viewport (`app.viewport`)
`scene`, `world`, `helpers`, `camera` (live), `objects` (id -> Object3D), `orbit`, `gizmo`, `stats {renders, lastMs, tris, calls}`, `render()`, `requestRender()`, `shadowsDirty()`, `loop(fn(dt, t)) -> stop` (return false to stop), `project(Vector3) -> {x, y, z}` (client px), `ndc`, `ray`, `pick(x, y, {objects, locked, filter}) -> hit`, `ground(x, y, h) -> Vector3`, `frame(ids, ms) -> Promise`, `setView(name, ms)`, `animateCamera`, `setOrtho(bool)`, `getCamera()`, `setCamera({pos, target, fov, ortho}) -> Promise`, `boxOf(ids)`, `refreshOutlines()`, `snapshot({w, h, type, quality, async}) -> dataURL` (async: a Promise; the pixels come back through a GPU fence, so the main thread never waits), `setInset(px, ms)` (keeps the scene centre above a bottom sheet). Objects with `userData.helper` stay out of thumbnails.

## UI (`app.ui`)
`toast`, `prompt(title, value, {label, ok})`, `confirm(title, {body, ok, danger})`, `form({title, body, fields: [{key, label, type: text|number|select|checkbox, value, options}], ok, wide}) -> values|null`, `alert`, `menu(items, x, y, {title, sheet})`, `contextMenu`, `sheet({title, items, render, cls})`, `openPanel(id)`, `refreshPanels()`, `openSide`, `closeSide`, `palette()`, `shortcuts()`, `icon(name)`, `isPhone()`. The phone layout swaps the sidebar for a bottom sheet.

## Commands built in
- Core: `edit.undo redo copy cut paste duplicate delete selectAll selectNone select group ungroup hide unhideAll lock set add reparent snap space`, `tool.select move rotate scale`, `file.new {name, empty, open} home rename duplicate`, `help.palette shortcuts`.
- Parts: `parts.box sphere cylinder wedge cornerwedge cone torus plane capsule` (Roblox names `parts.block`, `parts.part`, `parts.ball` and shapes `Block`, `Ball`, `Corner` work too) and `parts.insert` take `{shape, size, rot|rotation, pos|position, name, color, material, transparency, anchored, parent, select}` and return the id; `parts.rig {pos, torso, head, arms, legs, select}`; `parts.color {color}`, `parts.material {material}`, `parts.transparency {value}`, `parts.anchor`; `csg.union intersect negate`, `parts.toMesh`; `parts.array {count, offset}`, `parts.mirror {axis, at, copy}`, `mirrorX mirrorZ`, `parts.align {axis, to: min|center|max}`, `alignBottom alignCenterX alignCenterZ`, `parts.drop`. Selection commands take `{ids}` or use the selection.
- Camera: `view.front back left right top bottom iso ortho frame frameAll camera saveCamera fov {fov} grid bookmarkSave {slot} bookmarkGo {slot} bookmark1-3 setBookmark1-3`.
