# Studio: for AIs

How an AI edits projects (db docs, ops, headless export, export files, video). Format: [scene format](scene-format.md). Back to the [README](../README.md).

1. **Edit data directly** (fastest; open pages update live): Artifact data tool on this page's URL, `update` `projects/<id>` with only the objects you change, e.g. `{"objects": {"p7": {"type":"part","shape":"box","pos":[0,2,0],"size":[2,2,2],"color":"#e84d3d"}}}`.
2. **Run any command** (CSG, extrude, import, export): `set` `projects/<id>/ops/<opId>` to `{"cmd": "csg.union", "args": {"ids": ["a","b"]}, "status": "queued"}`. An open page of that project runs it and writes `status: "done"` + `result`, or `status: "error"` + `error`. Commands list: palette (`Ctrl+K`) or `studio.commands()`.
3. **In a browser**: `window.studio.run(cmd, args)`, `studio.scene()`, `studio.commands()`, `studio.open(projectId)`.
4. **Headless** (cloud session): `cd tools/3d/studio && node cli/studio.mjs export scene.json out.glb [--geo-dir dir]` (also `.gltf .obj .stl .ply .rbxmx .lua`; `.rbxmx` writes `meshes/*.obj` beside it), `validate scene.json` (exit 1 on errors), `info scene.json [--json]`. Input = the Studio scene `.json` export (mesh geometry inline in `geo`, or `--geo-dir/<geoId>.json`). Needs `npm i three@0.186.1` in a scratch folder (`NODE_PATH`), never committed. Textures and imported models are left out headless.
5. **Get an export file**: run op `io.export` with `{"format": "glb", "to": "assets"}`; `result.asset` is the asset id; read it with the Artifact tool (`read`, `path` = asset id).
6. **Video**: Export > Video (MP4, fast) (`format: "mp4"`, `plugins/video.js`, loaded on first use): the current clip as the view looks (no grid or gizmo), long side ≤1280 px, ≤30 fps, hardware H.264 at ~0.1 bit/pixel, stepped on the clip timeline: seconds to export, ~0.5 MB for 4 s. `quality: "render"` (menu: Video, 1080p render): every frame through Render image (1920x1080, 4x MSAA, AO, bloom, effects) at the clip's fps, ~0.3 bit/pixel: minutes, several MB. WebCodecs + mp4-muxer 5.2.2 (iOS/Safari 16.4+, Chrome 94+). Cloud check: `SHOTS_VIDEO=1` on the shots check writes `shots/clip.mp4` (fast).
- **Finished result in a fresh tab (owner):** every AI build is a new project: `set` `projects/<id>` (scene) and `meta/<id>` `{name, updated, count, ai: true, building: true}` (`updated` an ISO date; bump it in every stage's batch, set `building: false` in the last write: the tab's green dot shows only while building, and a finished build leaves the tab strip), written the fastest way; in stages (main shape → structure → details, bumping `meta.updated` each stage) only when the owner asks to watch. Open pages show it as a tab with a green live dot and update as each stage lands. Keep the project doc under 250 KB: short object ids, default fields left out. Only the model asked for: no Baseplate, ground or scenery unless the owner asks (owner).
- One project per AI. Work on different projects at the same time; never two writers on one project.
