# Images rules
- A named style = its `STYLES` row in tools/art/styles/index.html, verbatim; the "how it works" line is the checklist.
- Add-ons in list order: Roblox, Design sheet, Thumbnail. Mixes: 2-3 styles, each with a stated job.
- One best version per style: edit the row in place, never a second copy.
- Roblox thumbnails: built in the Studio, Look roblox (toon only for cartoon), Baseplate, one headline, 3-4 hooks, hero glow, Render image; 15 min max; look once.
- Avatars from real catalog items, never guessed.
- Mobile: prompts fully; thumbnail scene JSON + Artifact preview, queue the render in queue/pc.md.
- New failures go into domains/images/errors.md.
