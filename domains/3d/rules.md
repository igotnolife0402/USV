# 3D rules (applied lessons)
- Sub-agent model alias "sonnet" failed with model_not_found on this machine; omit `model` so the sub-agent inherits (L-001)
- Blender MCP: save the .blend before every execute_blender_code call; a bad script can crash Blender and lose work (L-010)
- Blender imported/generated assets arrive at arbitrary scale; size from world_bounding_box and place on ground (L-011)
- Artifacts cannot load external assets except pinned CDN libs; inline assets/procedural generation, pin exact CDN versions (L-012)
- Switching fast mode or model mid-session breaks the prompt cache; set both at session start (L-014)
- Sub-agent model alias "haiku" also fails with model_not_found on this PC (same as "sonnet"); never set model on agents (L-017)
- a test prop was exported with the result; mark test helpers temporary and exclude them from every export (L-021)
- live writes failed past size/count caps (doc 256 KB, ~150 objects per batch, a 658 KB mesh); measure payload size first, chunk writes, merge mass-repeated pieces into one mesh per colour (L-022)
- called a scene clean from desktop renders while the owner's phone showed z-fighting (layers 1-12 cm apart) and the tab pointed at deleted geometry; never stack surfaces, verify on the target's read-back (L-024)
- Root cause of L-017: the desktop app sets ANTHROPIC_DEFAULT_SONNET_MODEL/OPUS/HAIKU=auto, so every model alias resolves to "auto" (404); omit model or pass a full model id (L-031)
- Run the zfight check on the Studio tab read-back and judge on phone depth (SHOTS_DEPTH16=1); a desktop render proves nothing (L-036)
- Extend the Studio editor (tools/3d/studio) with a plugin before building a new 3D editor (L-039)
- keep owner tools in profiles/tools.md, search registry + scope all + fuzzy titles before asking, and save any link the owner gives the same turn (L-047)
- search Claude-Hub's index.html tool list (T: name, entry) before asking; hub tools are registered in profiles/tools.md (L-049)
- after importing generated .rbxmx, read key props back in Studio (Size, Texture, Lifetime) before judging visuals (L-061)
- client-side model scripts never assume descendants are loaded at start: DescendantAdded or WaitForChild (L-063)
- new/remade 3d models: max quality with the best kit (tools/3d/armor/hq.py); an older build is identity reference, not the quality bar (L-066)
- routes carry router.json fast entries: words -> exact files to open + skill override; hook injects FAST PATH and skips index/playbook/tool tables (L-067)
- models = many separate Studio parts (sphere/capsule/cone/cylinder/wedge) in joint groups; template beast/shadow_parts.py; blocks only when asked (L-074)

- mesh live builds: generator writes ready batch JSON per stage (geo+meta+project); read back meta only (count/version), never out_dir; no backslashes in heredoc python (L-089)
- crew easy builds: brain reads one template, skips router Read-first notes until review, spawns within 60 s (L-091)
