# /improve as an account-level Claude skill

Standalone copy of the vault's `/improve` (no vault files needed): works in any repo, any branch and plain claude.ai chats.
Install once: zip the `improve/` folder (`cd tools/skills/improve-standalone && zip -r improve.zip improve`), then claude.ai > Settings > Capabilities > Skills > Upload skill.
Keep it in sync with `.claude/skills/improve/SKILL.md` + `.claude/agents/improver.md` when those change.
