# Studio: limits

Back to the [README](../README.md).

- FBX export has meshes, materials and embedded textures, but no animation, bones or cameras; use GLB for animation.
- Imported skinned characters play and export their clips but are not mesh-editable.
- Downloads only allow some file types, so 3D formats download inside a `.zip` where the share sheet is not available; the dialog hint says so.
- 3MF has one colour per triangle: a textured or painted part prints in its texture's average colour.
