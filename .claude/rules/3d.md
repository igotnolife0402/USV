# 3D rules
- Blender MCP: call get_addon_status and get_scene_info first; save the .blend before every execute_blender_code.
- Split complex Blender work into small scripts; `look` after each meaningful step.
- Search asset libraries (Poly Haven, Sketchfab, Poly Pizza) before modelling; generate_3d only for one object.
- Rescale every import by its world bounding box to real-world meters and place it on the ground.
- Find shader nodes by type, never by localized name; read enum identifiers, never hardcode them.
- Apply transforms and export GLB with +Y up; materials = Principled BSDF + image textures only.
- three.js: pin versions in the import map, set sRGB output, tone mapping and an environment map.
- Browser mini-Blender = fork the three.js editor at a pinned tag (keep MIT LICENSE); do not rebuild gizmos/undo/tree.
- Mobile: write `*.blend.py` files and queue Blender runs in queue/pc.md; previews via procedural Artifacts.
- Done = checklists/3d.md; new failures go into domains/3d/errors.md.
