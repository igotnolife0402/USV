# 05 · "The mother of all roblox training vaults" (product promo, phone-filmed monitor)
101.6 s · 1016/1016 kept (handheld camera, every frame moves) · 44 caption cues → `sheets_cues/` (one frame per cue) was the useful view.
Mostly an advert for a third-party agent app. No game VFX. What's useful: how they structure and show a knowledge vault, which is close to ours.

## Claims (captions, timed)
- 3.5-9.8 s: the vault has 450k+ words and thousands of annotated images ("why things work, what doesn't").
- 16.6-28.4 s: agents read only the sections they need for the task during the first minutes (same as our router).
- 28.4-36.0 s: 13 chapters: core loop, rarity and RNG, progression and economy, UI, the first five minutes, the cozy loop, worlds...
- 36.0-47.3 s: live "comments" fly across the graph when an agent reads a note; click one to see what was read.
- 50-80 s: agents open Studio, upload assets, make thumbnails, effects, models; run overnight, controlled from the phone.
- 88-97 s: asset library (~1k free assets, sounds, UI icons) + a Discord.

## Visual: the vault as a galaxy (0.3-48.9 s)
- Each note = a glowing star (white core, soft purple halo); chapters = labelled clusters; links = thin white lines.
- A black-hole "house brain" with a purple accretion disc at the centre; nebula backdrop purple #5a2a9a → blue #1a2a8a with a teal #30e0b0 cluster.
- Reading activity = small white streaks travelling along links, plus a toast ("Lead is searching your notes...").
- Panels: gallery pages with screenshots + text ("Sword RNG X: the visual pack").

## What we take
- Our vault could show the same "agent read X" trail (we already log routed reads in archive/metrics.jsonl): a three.js Artifact galaxy of notes, coloured by domain, edges from index links, reads animated from the metrics log. Queued as a "Next" idea, not built (scope).
- Content chapters to check our roblox domain against: core loop, rarity/RNG, progression/economy, UI, first five minutes.
- Annotated images ("why it works") = what these analysis.md files now are.

## Not verified
- Any of the app's claims (word counts, overnight runs); it is advertising.
